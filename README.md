# Bid Detective 使用安装说明（EXE 版）

Bid Detective 是本地运行的招投标线索监控工具，支持中国政府采购网公开公告与已登录中招联合项目的统一检索、筛选、线索展示和 CSV 导出。

## 1. 安装与启动

1. 解压整个 `Bid Detective` 文件夹；**不得只复制 `Bid Detective.exe`**，必须保留同级的 `_internal` 文件夹。
2. 双击 `Bid Detective.exe`。程序会在后台启动，并自动打开浏览器页面 `http://127.0.0.1:8787`。
3. 首次运行会在 EXE 同级目录生成 `bid-detective.db`，用于保存本机配置和线索。该文件不上传至网络。

无需安装 Python、Docker、数据库或 AI API。

## 2. 中招联合登录来源（首次配置）

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择 `_internal\365trade-bridge` 文件夹。
4. 在 Bid Detective 点击“打开中招联合并登录”，用你自己的合法账号完成登录，并进入“寻找招标项目”页面。
5. 保持该“寻找招标项目”标签页打开，返回 Bid Detective，点击“我已登录，开始单次扫描”。程序会在后台复用这个标签页的登录状态，不会新建标签页或切换前台焦点。

扩展只将搜索到的项目列表回传至本机软件，不保存账号、密码或 Cookie。

当前同步桥版本为 **1.0.7**。升级 Bid Detective 后，请在扩展管理页先删除旧版同步桥，再从新版 `_internal\365trade-bridge` 重新加载；仅替换 EXE 不会自动升级浏览器扩展。

## 3. 配置与扫描

1. 将下列某一类别的关键词复制到“关注关键词（任一命中）”。可叠加多个类别。
2. 将不需要的项目类型复制到“排除关键词（命中任一则剔除）”。
3. 设置“公告时间范围（最近天数）”，默认 30 天；该范围同时控制中招联合导入、线索列表和 CSV 导出。
4. 点击“保存并扫描”或“一键扫描全部来源”。

关键词仅在**项目标题**中判断。排除词优先；“必须包含”中的每一个词都必须出现在标题内。

## 7. 线索、导出与故障排查

- 线索列表显示标题、来源、命中词、采购人、日期和详情链接；可单条或全部清除。
- 点击“导出 Excel CSV”可导出当前筛选范围内的线索。
- 中招联合显示“新增 0”通常表示详情链接已存在于本机线索库，不表示未扫描到项目。
- 若中招联合扫描失败，请确认扩展已加载、登录仍有效，并在扩展管理页重新加载扩展后重试。
- 扩展详情显示的版本必须为 `1.0.7`。旧版扩展会继续运行旧代码，是“网页能搜到、软件抓不到”的常见原因。
- 扫描报告会分别显示“网站结果、去重候选、通过本地规则、新增”数量；“新增 0”只表示本地已经存在相同详情链接。

请遵守各公告网站的服务条款、账号授权和访问频率限制。本说明不构成法律意见。
